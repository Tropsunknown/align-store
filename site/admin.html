Operations

Orders console.

Paste the Stripe session ID from your Discord notification, add the tracking number, and the customer gets an email with it. No database, no admin account — the shared token is the key.

The token is stored in this browser tab only. The worker compares it to ADMIN_TOKEN, then looks the session up in Stripe to find the customer’s email — so guessing a session ID gets you nothing.

Daily runbook

  1. Read Discord. Each paid order arrives as its own message with name, item, variant and full address.
  2. Order it. Open the supplier link in that message, buy it, ship to the customer’s address exactly as written. Do not “correct” the address.
  3. Note the order. Keep a spreadsheet row: date, Stripe session ID, supplier order number, cost.
  4. Wait for the tracking number from the supplier — usually 2–4 days.
  5. Paste it here. Customer gets a nice email automatically; Discord gets a “shipped” line.
  6. Refunds happen in the Stripe dashboard, not here.
Margin check: sell at 3–5× your supplier cost. After Stripe’s ~3% + 30¢ you should still clear 60%+.
